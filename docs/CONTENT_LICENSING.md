# Content and dependency policy

The Amber Keep map, stylized tokens, names and prose are original project materials; see `content/examples/amber-keep/ATTRIBUTION.md`. No competitor code/art, paid packs, fonts or sound files are copied. System fonts are used, including OS support for Slovak/Czech diacritics. Nothing loads from a CDN at runtime.

This increment contains **no D&D SRD data**. A future fantasy system must explicitly select and review its SRD release, record per-record provenance, include the exact attribution/license and keep SRD 5.1 separate from 5.2.1. The version cited by the master plan is a future implementation target, not a claim that any content has been licensed/imported here.

Runtime libraries are resolved from public Cargo/npm registries and pinned by lockfiles. Dependency license/security results and any outstanding audit limitation belong in PROGRESS/KNOWN_ISSUES before release. No public license has been selected for this private codebase; do not invent an MIT/CC grant on the owner's behalf.
